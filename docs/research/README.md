# 原始调研笔记（B 级素材）

这里放的是**未经逐条复核**的外部攻略调研笔记，只作为 `docs/赛季打法.md` 的取材来源保留。

⚠️ **不要直接引用这里的数值。** 这些笔记里的卡牌数值大量来自中文社区文章，
写作过程中已发现至少 11 处与卡表冲突（星级、身材、卡文都可能有出入）。
`docs/赛季打法.md` 里凡有分歧的地方都以卡表（`data/cards_zhCN.json`）为准，并单列了「⚠️ 卡表纠正」小表。

这些笔记的价值在于三件事：

1. **思路**：连招顺序、站位意图、打法之间的区别 —— 这些卡表里读不出来。
2. **被削历史**：哪张牌在哪个补丁被砍成了什么样 —— 能解释「为什么攻略说的和现在不一样」。
3. **「未找到」清单**：明确记录了哪些问题是查不到的（升本表、站位表、克制关系），
   避免后面有人重复去挖同一口枯井。
