### 必须先纠正的三条候选牌事实

1. **「宝石切分者」（Gemsplitter，BG21_037，3 星 2/1 圣盾·友方随从失去圣盾后获取 1 张鲜血宝石）本赛季已不在卡池**（`isBattlegroundsPoolMinion` 未标记，且不在 wiki.gg 的 27 张野猪人卡池列表中）。
2. **「卡尔加」（Charlga，BG20_303，6 星 3/3 回合结束对自身以外的所有随从各使用 2 张鲜血宝石）本赛季同样不在卡池**。注意 hsreplay 的赛季 14 流派列表里存在一个名为 `Quilboar - Charlga` 的流派（comps/65），与卡池数据冲突，**未找到解释**，建议以游戏内卡池为准。
3. **「囚牢恶霸」的星级变过一次，两边线索都对，只是版本时点不同。** 它 **36.2.0（2026-08-04）上线时确实是 5 星 2/7**（这正是 3DM / 18183 中文攻略的写法），**36.2.2（2026-08-18）被移到 7 星并改为 6/15**，所以「七星」是当前（36.6.3）状态。**两个说法都能被官方数据支持**；触发词只有一个正确答案：**进击（Rally）**，不是战吼。详见 §2.1。

### 1.2 关键词继承（圣盾 / 烈毒）到底怎么来

- 游戏里的「**额外关键词 / Bonus Keyword**」只有 6 种：**圣盾、复生、潜行、嘲讽、烈毒、风怒**。
- 判定规则：**圣盾、复生、潜行、烈毒在被吞食时会正常丢失**；嘲讽和风怒一般不会被移除。**只有当效果明确写「获得其额外关键词」时才继承**——也就是 `理性癫狂` 与饰品 `吞魔之爪`。
- 因此「圣盾烈毒恶魔」的实际配方是：
  1. 用 `灵巧的逃亡者`（发动 1，酒馆全体 +8/+8 并给**嘲讽 / 圣盾 / 风怒**三选一）或 `珠宝盒`（野猪人向，见 §2）等方法把关键词贴到**酒馆里的随从**身上；
  2. 用 `理性癫狂` 吞噬 → 获得属性值 **+ 额外关键词**；
  3. 或挂上饰品 `吞魔之爪`，让**任何**吞噬动作都附带额外关键词。
- 若没有 `理性癫狂` / `吞魔之爪`，普通吞噬（乌祖尔、缚魂狱卒、腐化糕点）**不会**带回圣盾或烈毒。

### 1.4 升本节奏与操作顺序

- **可考证的部分（社区二手来源）**：
  - `18183「十种族一套阵容攻略」`把恶魔评为 **T0.5**，描述为：「核心：吞噬，连关键词都能吞，圣盾烈毒恶魔不是梦」；「养酒馆核心：**恶魔干扰者**：任意指向性法术永久提升酒馆身材」；「法术来源：**鬼影幻术师**、**理性癫狂**」；「配合：**巴琳达**双倍养酒馆 + 双倍吞酒馆」。
  - `3DM 转载旅法师营地`：「对恶魔干扰者打出法术养酒馆，同时邪能野猪人吃酒馆。鬼影幻术师亡语获得理性癫狂，使恶魔吃掉酒馆中随从的关键词，获得圣盾、复生、烈毒等关键词。」
  - 由此可确定的**节奏骨架**：2–3 星用 `实验室助理 / 受困的钟舌恶魔` 铺恶魔饲料；4 星起拿 `鬼影幻术师 + 缚魂狱卒 + 灰烬腐蚀者` 并开始囤 `理性癫狂`；5 星拿 `恶魔干扰者 + 贪食的乌祖尔 + 邪能野猪人`；6 星上 `巴琳达` 把「养酒馆」和「吞酒馆」同时翻倍。

### 1.6 弱点与克制

- 可证实的结构性弱点（由卡面数据直接推出，非社区口径）：
  1. **产出依赖指向性法术**：`恶魔干扰者` 只认「对本随从施放」的法术，`巴琳达` 又锁在 6 星，前期没有法强引擎时酒馆身材起不来。
  2. **关键词继承需要专门部件**：没有 `理性癫狂` / `吞魔之爪`，「圣盾烈毒恶魔」不成立。
  3. **`缚魂狱卒`、`理性癫狂` 都是「随机吞食」**：随机吞食会把酒馆里的关键随从（例如刚被贴了圣盾的那只）吃掉。而**本赛季唯一能指定「吞生命值最高」的饰品 `鬼儡肖像` 已不在池中**，所以这条「稳定性」缺失在本季是**实打实的弱点**。
- 社区口径（低置信度）：
  4. **操作/性能瓶颈**：vgover 称该流派「手动流被卡顿 Bug 限死、**手机端基本玩不了**」——每次吞噬都有动画与逐个结算，回合时间不够。
  5. **极度依赖经济**：养酒馆 + 吞酒馆两套动作都要花钱，铜须/经济组件是刚需。
  6. **缺狂战斧/剧毒**（旧文口径，36.x 是否仍成立未验证）。
- **反直觉的一点**：网易号在 36.4.2 后称「恶魔 更新前 T2 → 更新后 **T0**……吃鸡能力第一」，即当前恶魔是**强势方**，弱点主要是操作而非强度。

## 2. 野猪人 —— 社区称「鲜血宝石 / 摩托猪」

### 2.1 「摩托猪」考证（重点结论）

- **「摩托猪」= 极速野猪骑士（Turbo Hogrider，BG31_323，6 星 6/8）**，不是本季新卡。
  - 官方中文名是 **极速野猪骑士**，卡池里确实**没有**任何叫「摩托猪」的牌——父任务的前提正确。
  - 英文名 Turbo Hogrider 的发音/造型被社区昵称为「摩托猪」，wiki 页面记录的登场语音为 **"Wroom wroom!"**，是昵称来源。
  - 效果文本：「在你使用一张抉择牌后，本随从对你的所有野猪人各使用 **2 张鲜血宝石**。」
  - 版本轨迹：Patch 31.2.0（2024-12-03）加入 → 32.2.0（2025-04-29）**移除** → **36.2.0（2026-08-04）回归**。所以它是「回归的老卡」，符合 18183「回归：摩托猪抉择体系」的说法。
  - 36.6.3（2026-10-01）把它从 5/7 上调为 6/8，并把文本从「对所有其他野猪人各使用 1 张」改为「对你的所有野猪人各使用 2 张」。
- **「囚牢恶霸」= Jailbird Juggernaut（BG36_333）。当前（36.6.3）是 7 星 6/15（金色 12/30）；上线时（36.2.0）是 5 星 2/7。**
  - 官方中文文本：「**进击**：召唤一个具有本随从属性值的魔像，并使其率先攻击目标。」金色为「双倍属性值」。
  - **星级轨迹（把两条线索对上）**：36.2.0（2026-08-04）以 **5 星 2/7** 加入 → 36.2.2（2026-08-18）**移至 7 星、改为 6 加攻击 / 15 生命** → 36.4.2（2026-09-03）文本由「属性值等同于本随从的鲜血宝石」改为「等同于本随从的**属性值**」 → 36.6.3（2026-10-01）一度移出后**回归卡池**。
  - 因此 3DM（2026-08-05）与 18183（2026-08-11）写「五星 2/7」**在当时是对的**（文章早于 36.2.2）；父任务线索里的「七星」与当前卡池一致。**唯一需要纠正的是触发词**：3DM 与 18183 都写「战吼」，官方为「**进击（Rally）**」。
  - 补充：它的进击**无法被人工重复触发**（卡牌标签 `BACON_RALLY_CANT_BE_ARTIFICIALLY_TRIGGERED`），其召唤物是 token **鲜血魔像 Blood Golem [BG30_MagicItem_442t]**。
  - 18183 标题里的「**一打七**」是双关（七星 / 一挑七）。
- **「宝石特训」= Gem Day [BG31_893]**，是一张抉择法术：「抉择：在本局对战中，你的鲜血宝石会使随从额外获得 **+1 攻击力**；或者 **+1 生命值**。」它不是卡池直售法术，来源为 `健身搏猪`（回合结束获取一张）与 `坑谷矿工`（抉择二选一）。
- **「吸宝石」= 查抄宝石 Gem Confiscation [BG28_698]**，4 星酒馆法术、1 铸币：「本牌对一个随从使用 3 张鲜血宝石，并使其**偷取相邻随从的所有鲜血宝石**。」
- **鲜血宝石** 本身是野猪人专属法术 [BG20_GEM]：「使一个随从获得 +1/+1。」卡池里还有三种变体，额外给**野猪人**贴上关键词：`BG20_GEM_DivineShield`（圣盾）、`BG20_GEM_Reborn`（复生）、`BG20_GEM_Taunt`（嘲讽）。

### 2.2 体系运作原理

两条产出线 + 两条收割线：

- **A. 抉择牌 → 极速野猪骑士 → 全队打宝石**（这就是「摩托猪体系」）
  - `极速野猪骑士` 每被打出一张抉择牌，就给**所有野猪人**各上 2 张鲜血宝石。
  - 抉择牌来源：`棘刺挖掘工`（4 星 3/6 进击：随机获取一张抉择牌）、`圈套陷阱师`、`狡猾的渗透者`、`无畏的食客`、`坑谷矿工`、`刺棘开拓者`（每回合一张抉择牌同时拥有两种效果）、酒馆法术 `范达尔的佑护`、饰品 `透视玻璃杯`（每回合获取抉择牌）。
  - **`开拓者标签`（BG36_MagicItem_308）：你的抉择牌同时拥有两种效果**——把「获取资源」和「加宝石质量」合并，是 18183 点名的首推饰品，也解释了为什么它同时被 18183 的 T0.5 总结收录。
- **B. 提高鲜血宝石质量（养宝石）**
  - `宝石特训`（+1 攻 或 +1 血，本局）
  - `无畏的食客`（3 星 2/4 抉择：血宝石额外 +1/+1；或获取 4 张）
  - `鲜血精研者`（5 星 3/8 进击：血宝石额外 +1/+2）
  - `鲜血勇士`（6 星 9/4 战吼亡语：额外 +2/+1）
  - `热气球测绘员`（4 星 3/7：**从手牌中使用的鲜血宝石会额外施放一次**）—— 质量翻倍器
- **C. 收割：把宝石集中到 `囚牢恶霸` 的魔像上**
  - `查抄宝石` 把相邻随从的所有宝石偷到一个随从身上 → 全部喂给 `囚牢恶霸`
  - `囚牢恶霸` 进击召唤「属性值等同于本随从」的魔像，并**让魔像率先攻击**
  - 18183 描述的循环（二手来源，非卡面事实）：「魔像先出手 → 把对面的怪打死 → 囚牢恶霸不需要再次出手 → 只要够大就能无限后撤步，不断召唤超大魔像」
- **D. 一次性爆发**
  - `老牌恶匪`（6 星 8/8）抉择：本随从对你的所有随从各使用 3 张鲜血宝石；或**施放 3 次鲜血宝石弹幕**
  - `鲜血宝石弹幕`（4 星酒馆法术 1 铸币）：本局对战中，在酒馆刷新后，使其中的随从获得 +2/+2 的鲜血宝石
  - `得胜的地卜术师`（6 星 10/10 发动 2）：获取 6 张鲜血宝石，放不下的施给最左随从

### 2.5 升本节奏与操作顺序

以下为 **18183（2026-08-11）二手攻略**的三阶段口径，卡面事实已交叉验证，节奏本身未获权威来源确认：

| 阶段 | 打法 |
|---|---|
| 前期：养宝石质量 | `健身搏猪` 提供 `宝石特训`；`坑谷矿工`；`棘刺挖掘工`（18183 写作「挖掘工 四星 3/6 战吼随机获取一张抉择牌」，与官方卡面一致，仅「战吼」应为「进击」） |
| 中期：摩托猪养全场 | `极速野猪骑士` 不断刷抉择牌，给全员野猪人打宝石；配合 `邪能野猪人` 与 `巴琳达` 吃酒馆 |
| 后期：吸宝石集中 | 用 `查抄宝石` 把全员野猪人身上的宝石吸给 `囚牢恶霸`；若拿不到，用 `堑壕斗士` 回合结束提供 |
| 终极 | `囚牢恶霸` 宝石足够多 → 魔像先手秒人 → 18183 所称「无限后撤步」→ 一打七；`老牌恶匪` 收尾 |

- **3DM（2026-09-24）对循环的逐字描述**：「野猪抉择猪：**棘刺挖掘工和健身搏猪获得抉择牌，打出抉择牌触发极速野猪骑士的效果对野猪使用鲜血宝石**。」——这句把「抉择牌产量 = 宝石产量」的换算关系写死了，是理解本体系的关键。
- **升本节奏（仅有低置信度社区口径）**：9game 攻略称「**速三本抢健身搏猪**（越早启动越快）」「**升五天选给极速野猪骑士基本可宣告吃鸡**」「同行一般 3–4 个」。此为自媒体口径，未获官方或数据站确认。
- **社交/操作成本（社区痛点）**：NGA 有帖标题《**摩托猪的动画慢得令人发指**》，指其每次抉择都要对全场野猪人逐一打宝石，操作与动画耗时极长；另 9game 提醒野猪人容易**爆牌**（手牌被鲜血宝石塞满）。
- **未找到**：本季野猪人体系**逐回合的升本数字表**（第几回合该有几本几血）、完整的 7 人站位图、以及「摩托猪体系」的英文社区（Reddit r/BobsTavern）对应攻略正文。
- 版本变动（18183 说法）：移除**爵士乐手**（Moon-Bacon Jazzer）与**粉皮猪**；新核心为 `宝石特训`；`摩托猪` 抉择体系回归。

### 2.6 站位

- **可考证**：`囚牢恶霸` 的魔像**率先攻击目标**，所以 `囚牢恶霸` 本身通常不需要站最前；`得胜的地卜术师` 的溢出血宝石固定施给**最左边**的随从，因此最左位应放主要打手（如 `囚牢恶霸`）。
- **未找到**本季野猪人体系的完整站位（7 个位置的摆放顺序）权威指导。

### 2.7 弱点与克制

- 可证实（由卡面推出）：
  1. **硬依赖 `极速野猪骑士`**：18183 直接写「核心：摩托猪（**唯一发育核心，拿不到就没发育**）」。
  2. **`囚牢恶霸` 是 7 星牌**（36.2.2 起）：必须能上 7 本（或通过 `降圣仪式`「发现一个等级 7 的随从」等途径）才拿得到；36.2.0–36.2.2 期间它是 5 星，门槛低得多。
  3. **宝石集中在单点**：`查抄宝石` 把宝石全堆到 `囚牢恶霸` 身上，一旦魔像被烈毒点掉或 `囚牢恶霸` 被换掉，收益归零。
- 社区口径（低置信度，多为 NGA 帖标题级证据，正文 403 未能读取）：
  4. **中期脆弱**：NGA《野猪人确实很强，但是**中期也太脆弱了**，基本上没什么高质量打手》。
  5. **前中期缺宝石**：TapTap 玩家实测「本来玩野猪就容易养不大宝石，或者就是没有宝石」。
  6. **同行内卷**：9game 称「同行一般 3–4 个」，卡池里抢同一张 `极速野猪骑士`。
  7. **动画/手速瓶颈**：见 §2.5「摩托猪的动画慢得令人发指」。
- 决赛被通用针对（iyingdi 入门攻略，通用而非野猪人专属）：对手野兽 → 架妈人/辛多雷/召甲虫；对手机械 → 食尸鬼；对手海盗 → `火车王` 放嘲讽旁；决赛通用随从 `火车王`、剧毒鱼、剧毒娜迦、变色龙；决赛法术 变 1 血、召唤甲虫（破盾卡频率）。

## 5. 来源可靠性分级与已知陷阱

**A 级（可直接引用）**：HearthstoneJSON `zhCN` / `enUS` 官方卡牌库（卡名、星级、身材、效果原文的**唯一**依据）；暴雪官方公告与官方论坛补丁说明；hearthstone.wiki.gg 的 Battlegrounds 卡牌页与补丁页。

**B 级（实读正文，卡名数值可信、措辞需交叉验证）**：旅法师营地的卡牌预览与补丁中译（`battle.com` / `iyingdi.com`）、3DM 转载文、17173、游侠网、TapTap 实测帖、游戏狗机制答疑。

**C 级（无正文，仅标题级旁证）**：全部 NGA 帖（`bbs.nga.cn` / `ngabbs.com` 对访客返回 **HTTP 403「访客不能直接访问 (ERROR:15)」**）、B 站、百度贴吧。

**已确认不可引用的来源（重要陷阱）**：

1. **18183《恶魔养酒馆》（2026-08-12）** 出现卡库中**不存在**的卡名「理性巅峰 / 扭曲俯视 / 黑暗之刺」——该页**卡名一律不可引用**，只有与官方库对得上的描述可用。
2. **3DM 页面编号 71811 / 71088** 页面日期新但正文是**早年回收内容**（文中 `二王`、`玛尔加尼斯`、`安尼赫战场军官` 在战棋卡库中均 NOT FOUND）。
3. **9game《双头飞龙野猪人玩法攻略》** 为通用 AI 式批量文，与 36.x 摩托猪体系不符。
4. **iyingdi 第九赛季合集** 称「恶魔是版本陷阱慎玩」，与 36.x 恶魔 T0 的结论**相反**，勿跨版本混用。
5. **3DM / 18183 的野猪人攻略**把 `恶魔干扰者的加值` 写成 +2/+2（现行为 **+1/+2**，已被下调）、把 `囚牢恶霸` 的触发词写成「战吼」（官方为「**进击**」）、把 `棘刺挖掘工` 也写成「战吼」。**卡名与体系骨架可用，数值与时态需以官方库为准。**
6. **18183 把 `囚牢恶霸` 写作「五星 2/7」** 在发文时点（36.2.0–36.2.2 之间）**是对的**，36.2.2 起已改为 7 星 6/15。
