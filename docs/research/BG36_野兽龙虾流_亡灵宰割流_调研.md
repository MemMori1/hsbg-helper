## 1. 野兽：龙虾流 / 龙虾亡语

### 1.1 核心机制

- **美味龙虾是成长源**：龙虾亡语给野兽加身材，且**「提升你此后美味龙虾的效果」**——即龙虾死亡次数越多，之后的龙虾效果越强，是可**永久保留**的滚雪球数值。——[iyingdi 36.2预览（六）](http://mob.battle.com/post/5675216)、[搜狐](https://m.sohu.com/a/1059710964_121124834/)
- 搜狐原文：「龙虾是目前最强的流派，而且操作简单无脑，**龙虾死的次数越多，它的战力就越强**，配合进击随从和 6 星的陆行鸟**多倍触发龙虾亡语**，身材能瞬间成百上千。」
- **「招募阶段也能触发亡语」是本体系最变态的点**：搜狐原文「这套阵容最变态的是**可以在招募阶段通过诱饵触发进击随从，触发龙虾的亡语，从而永久保留龙虾的 buff 数值**。」

### 1.3 招募阶段连招顺序（核心）

18183 原文编号（[f5pdello](https://m.18183.com/gonglue/202608/f5pdello.html)）：

1. **最左放狮鹫**
2. **鱼饵触发狮鹫**
3. **进击攻击鱼饵**
4. **进击触发陆行鸟 → 触发龙虾亡语**
5. **同时获得野兽资源**

3DM 的操作阶段版本（[354502](https://ol.3dmgame.com/gl/354502.html) / [353116](https://ol.3dmgame.com/gl/353116.html)，两篇文字完全相同）原文：

> 「野兽龙虾流：**进击随从攻击时，逐亡陆行鸟触发龙虾的亡语**使野兽获得成长。**操作阶段可以出售尖利的鲨鱼或者发动深潜狮子鱼的效果，使猎头狮鹫攻击酒馆**，从而触发进击效果获得野兽，此时陆行鸟触发美味龙虾获得成长。**若猎头狮鹫给的是尖利的鲨鱼，即可倒转。**辛多雷也是不错的进击随从。」

即：
- 常规循环：狮鹫（或任意进击随从）攻击鱼饵 → 陆行鸟触发最左亡语（龙虾）→ 龙虾 buff 永久累积。
- **倒转**：狮鹫进击给的恰好是「尖利的鲨鱼」→ 出售它 → 又刷出一个鱼饵并让最左野兽再攻击一次 → 继续触发进击/亡语，形成闭环。
- 触发鱼饵的两种手段：**出售尖利的鲨鱼**，或**发动深潜狮子鱼**（按「发动」关键词结算）。

### 1.6 站位

有来源支持的两条：
1. **狮鹫放最左**——因为鱼饵/鲨鱼/狮子鱼都是让「**最左边的野兽**攻击鱼饵」，狮鹫在最左才能被这个效果驱动进击。——[18183 f5pdello](https://m.18183.com/gonglue/202608/f5pdello.html)
2. **龙虾要成为「最左边的亡语」**——陆行鸟触发的是「你最左边的亡语」，所以龙虾（或你想复读的亡语）必须在亡语随从中位于最左。18183 明确写「核心组件：陆行鸟（进击时触发**最左边**的亡语）」。——[18183 06u8mpjh](https://m.18183.com/gonglue/202608/06u8mpjh.html)

> 注：两条站位约束可以同时满足——狮鹫本身没有亡语，占 1 号位不影响「最左亡语」的判定（此推论为文本互证，非来源直述）。

### 1.7 操作顺序（汇总）

**招募阶段（永久收益）**：最左狮鹫 → 用鲨鱼/狮子鱼造出鱼饵 → 狮鹫攻击鱼饵（进击：拿一张野兽）→ 陆行鸟触发最左亡语（龙虾）→ 龙虾永久变强。
**战斗阶段**：进击随从攻击即触发陆行鸟 → 复读龙虾亡语 → 全场野兽持续成长；有狼头链锤则回合结束时再结算一次亡语。

### 1.8 弱点 / 克制（有来源的部分）

- **36.2.2 大削**：开发者注原文「美味龙虾在早期环境中出场率极高且表现非常稳定，**明显挤压了其他流派的空间**。因此，我们**大幅削弱了其亡语效果，将其数值减半**。我们还决定**继续禁用囤食土狼**。」——[iyingdi 36.2.2](http://mob.battle.com/post/5678454)
- **黑暗之赐「魅力感召」禁用名单**（直接影响本体系）：提图斯·瑞文戴尔、咆哮募兵龙、啮笼鼠、香蕉猛猿、深潜巨兽、时尚魅影、障蔽女妖、暴虐巨蝎、巴琳达·斯通赫尔斯、**逐亡陆行鸟**。——同上
- **难度评级**：龙虾野兽在 36.6.1 榜单为 **A 级、难度低**（对比亡灵宰割为 S 级、难度高）。——[ali213 1813247](https://m.ali213.net/news/gl2609/1813247.html)

## 2. 亡灵：宰大哥 / 宰割流

### 2.1 核心机制

- **宰割**（酒馆法术，售价 2 铸币 / 等级 5 级）：**消灭一个友方亡灵。在本局对战中，你的亡灵额外拥有等同于该随从等级的攻击力。**——[3DM 282702](https://ol.3dmgame.com/gl/282702.html)
- **时尚魅影**（6 星 6/8 亡灵）：**在一个友方随从复生后，使你最右边的亡灵获得等同于复生的随从攻击力的属性值。**——[3DM 349023](https://ol.3dmgame.com/gl/349023.html)（来源标注：旅法师营地 / Bennidge）、[iyingdi 36.2预览（十二）](http://mob.battle.com/post/5712500)
- 因此**「宰掉高攻复生亡灵 → 时尚魅影把它的攻击力复制成最右亡灵的双维」**：18183 举例「宰掉 200 攻的复生随从 → 最右亡灵获得 **+200/+200**」。——[18183 f5pdello](https://m.18183.com/gonglue/202608/f5pdello.html)
- 搜狐原文解释其价值：「宰割流在原来的基础上加了新卡 6 星时尚魅影，在一个随从复生后，最右边的亡灵会获得其攻击力的属性值，**以前宰割流只有高攻击低血量，现在血量也能飞速提升了**。」「这阵容变态的地方也是**可以在商店招募阶段通过宰割/消灭复生随从，永久保留 buff 身材**。」——[搜狐](https://m.sohu.com/a/1059710964_121124834/)

### 2.3 运作方式（宰掉复生亡灵 → 时尚魅影）

3DM 36.6 原文（[354491](https://ol.3dmgame.com/gl/354491.html)，2026-09-24）：

> 「亡灵宰割流：**友善的恶鬼养酒馆法术攻击，断手提供亡灵频率，堕落屠夫的复仇效果获得宰割法术，宰割养亡灵的攻击。宰割带复生的亡灵，触发时尚魅影的效果养最右边亡灵的身材。**丧钟死灵、木乃伊工匠可『无限』宰割。」

3DM S14 版（[349006](https://ol.3dmgame.com/gl/349006.html)）同一段结尾为：「…**同时障弊女妖给复生后的随从带上圣盾**。丧钟死灵、木乃伊工匠（消灭、亡语）、义肢假手均可给亡灵带上复生。」

18183 的补充：「后期**丧钟死灵 + 木乃伊工匠联动，一块钱切一个亡灵，每回合十张宰割**。」——[4kr748gl](https://m.18183.com/gonglue/202608/4kr748gl.html)

循环拆解（来源直述 + 文本互证）：
1. **产法术**：德鲁斯特堕落屠夫（复仇）拿「宰割」；友善的恶鬼让酒馆法术额外 +攻击力。
2. **铺复生**：义肢假手 / 木乃伊工匠 / 丧钟死灵 给亡灵挂**复生**。
3. **宰**：用「宰割」或「消灭」手段杀掉**高攻的复生亡灵**——它带着 1 血复活，同时把攻击力写进宰割的永久攻击加成。
4. **复制身材**：该随从「复生」这一事件触发**时尚魅影** → **最右边的亡灵获得等同其攻击力的 +X/+X**（攻防一起涨）。
5. **滚雪球**：丧钟死灵 + 木乃伊工匠互喂复生，形成「无限宰割」。

### 2.7 操作顺序（汇总）

每回合（招募阶段，收益永久保留）：
1. 用堕落屠夫等拿到**宰割**（友善的恶鬼同时给法术堆攻击力）。
2. 确认场上有一个**高攻 + 带复生**的亡灵（义肢假手/木乃伊工匠/丧钟死灵提供复生）。
3. 对它使用**宰割**（或消灭手段）→ 它以 1 血**复生**。
4. 复生事件触发**时尚魅影** → **最右亡灵 +X/+X**（X = 该随从攻击力）。
5. 用**丧钟死灵 / 木乃伊工匠**互喂复生，重复 3–4 步（「无限宰割」）；障蔽女妖在复生后获得圣盾撑住。
