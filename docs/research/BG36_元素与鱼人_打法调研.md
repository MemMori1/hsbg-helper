# 一、元素：【雷暴流 / 养酒馆元素】

## 1.1 当前版本定位

- 【二手攻略】17173《龙虾跌落神坛！黄金棋坛可以玩哪些种族？》（2026-08-22，作者 @炉石传说-炉指导）给出的天梯体感梯度：**T0 = 元素、纳迦；T1 = 鱼人、恶魔；T2 = 海盗、机械；T3 = 野猪、龙；T4 = 野兽、亡灵**。该文对元素的描述要点：灯神回归并带战吼与亡语，四本有酒馆旋风，经济充裕，有铜须可轻松倒转，**上限依然是无羁雷暴阵容**。

## 1.6 操作顺序（含重点：酒馆刷出冰灵时刷元素，使雷暴收益最大化）

**先把机制说清楚（全部来自【官方卡面】，结论属【机制推导】）：**

1. **无羁雷暴的收益只取决于「结算瞬间酒馆中生命值最高的随从」**——它不看你场上谁最大。
2. **缤纷冰灵是唯一「在酒馆里也能同步长大」的养酒馆目标**：文本写明「你每使用过一张元素牌，便拥有 +2/+1（**无论本随从在哪**）」。所以只要冰灵躺在酒馆里没被买走，你每打出一张元素牌，就同时推进了雷暴的计数**并且**把酒馆里的冰灵身材顶高。
3. 雷暴的括号计数（还剩 4 张！）表明它是**反复触发**制：每用满 4 张元素就再结算一次，不是一次性。
4. 金色雷暴（`BG36_352_G` 6/24）结算为**双倍**属性值。

**由此得出的最大化操作顺序（【机制推导】）：**

1. **先铺「养酒馆」引擎再数元素。** 让爆焰灯神（战吼，铜须在场触发两次）、农场热舞旋风（战吼+亡语）、活化艾泽里特（吃到酒馆法术）、诺米标签饰品把酒馆里元素的身材先抬起来。**不要在养酒馆引擎还没就位时就把元素张数打满**。
2. **酒馆一旦刷出缤纷冰灵，先别买。** 把它留在酒馆当「受体的血量池」，然后开始连打元素：每张元素 = 雷暴计数 +1 且冰灵 +2/+1（金色 +4/+2）。
3. **把第 4 张元素留到「酒馆里有大身材」的那一刻再打**（冰灵已在酒馆、或乘借东风/灯神刚给酒馆灌过 +8/+8 与 +10/+10）。这第 4 张一结算，雷暴直接吃下当前酒馆最高血量随从的属性值。
4. **空气亡魂/袋中旋风=免费的养酒馆触发器。** 空气亡魂按「花掉 7 枚铸币」施放乘借东风，与铜须＋刷新（刷新畸体、酒馆旋风找元素）形成「花钱 → 养酒馆 → 再花钱」的循环；袋中旋风饰品每回合开始白送一次乘借东风。
5. **用魔焰执行者/活体监牢把酒馆身材取出来。** 魔焰执行者每回合结束吞食酒馆最高血量随从；活体监牢 发动(1) 直接吃「本回合买下的下一个随从」的属性值——两者都是把「酒馆身材」落到场上的出口。
6. **战斗端收尾**：极紫外升腾者战斗开始给其他元素 +3/+3（且随你使用元素牌提升），沟渠守护元素进击永久给元素 +2/+2；野火元素负责溢出伤害清场。
7. **铜须贯穿全局**：它既是战吼双倍（灯神/热舞旋风/酒馆旋风），也是拿铜须肖像饰品的理由之一。

> **社区原文只说到「不断打出元素，使无羁雷暴获得酒馆身材」这一层**（36.6 一图流）。上面 1–7 的先后次序是由官方卡面文本推出的操作实现，未在任何可访问的中文/英文攻略中找到逐字表述。

## 1.7 站位

- 【未找到】BG36 元素雷暴流的站位（谁左谁右、嘲讽位、亡语位）没有可核实的来源。
- 【二手攻略】早期元素攻略给出的通用原则（同样标注为版本可能不符）：光铸类圣盾增益置于中段以覆盖更多友方；高攻元素前置吸收伤害并触发亡语；召唤/特效型元素后置。
- 【机制推导】两条对元素本家成立的站位置信度较高：**野火元素应放在最靠前且两侧有敌人的位置**（其溢出伤害打相邻敌人）；**沟渠守护元素需要靠进击触发**，所以它要能打出去（前置）；**达卡莱附魔师/极紫外升腾者这类「回合结束/战斗开始」光环放后排**。

## 1.8 弱点与克制

- 【官方预览】36.6.3 官方削弱了畸变怪体系，等于间接承认元素在同补丁中获得相对加强；同补丁元素几乎全是加强项。
- 【二手攻略】对元素的通用反制：**超管棘化荆蔓女巫**（把目标变成 3/3）对堆身材的元素威胁极大；元素操作耗时长（手速流），容易被跳蛙、亡灵等长战斗/亡语阵容在战斗时长上克制。
- 【HSReplay】元素流派签名（`compositions/39/`，as_of `2026-09-24T16:47:05Z`，n=37）本身携带了「答案」：权重最高的组件依次为 **无羁雷暴 0.585、布莱恩·铜须 0.530、魔焰执行者 0.412、野火元素 0.390、巴琳达·斯通赫尔斯 0.372、空气亡魂 0.286、酒馆旋风 0.177、莽神火车王 0.163、活体监牢 0.158**。注意**「莽神火车王」「致命的孢子」等毒/解场牌有稳定出场率**，说明元素阵容在天梯需要为「被贴毒」准备解场位。
- 【机制推导】元素真正的软肋是**成型前的空窗期**：雷暴是 6 星，养酒馆引擎（灯神/热舞旋风/艾泽里特）全在 4–5 星，前期只靠熔融岩石这类 +1 生命的瘦子，容易被 4–5 回合的高节奏阵容直接打出局；而一旦对手拿到「烈毒/超管」，你堆出来的单体大身材会被一次性抹平。

## 2.6 操作顺序（含重点：逃生飞龙在招募阶段触发怒胆鱼人贴烈毒）

### 关键前提：官方对「发动」的定义（这条是本次调研最重要的机制查证）

【官方机制】3dmgame 2026-07-28《炉石传说新关键词发动效果介绍》（标注来源：官网）原文：

> **「发动是一个全新关键词。部分随从会获得特殊能力，可在招募阶段花费铸币触发，让你以全新的方式调配资源。只要该随从在你的战队中，点击它即可触发其能力。每项发动能力每回合只能使用一次。把握好发动时机，让每枚铸币都物尽其用！」**

这条定义**直接证实**了用户所问的连招在规则上成立：**发动 = 招募阶段、花铸币、点击触发、每项每回合一次**。

### 连招 1：天诞逃生飞龙 → 怒胆喷毒鱼人 → 招募阶段给鱼人贴烈毒【机制推导，依据=官方机制＋两张官方卡面】

- 天诞逃生飞龙（`BG36_243`，4 星 4/7 龙）：**发动（1）：**触发一个友方随从的**进击**效果。
- 怒胆喷毒鱼人（`BG33_318`，5 星 1/10 鱼人）：**烈毒。进击：**使另一个友方鱼人获得**烈毒**。

操作：把天诞逃生飞龙和怒胆喷毒鱼人都放在**战队**里 → 在**招募阶段**点击天诞逃生飞龙、花 1 枚铸币 → 它触发怒胆的进击 → **当场（战前）** 给另一个友方鱼人贴上烈毒。每回合每项发动一次，所以每回合都能在战斗开始前多贴一层毒，**不需要等到战斗回合内才碰运气触发进击**。

> 注意：贴毒的目标是「另一个**友方鱼人**」，因此被点名的那个随从必须是鱼人（或通过「铜须肖像」把铜须视为鱼人）。

### 连招 2：手牌鱼的经济-成长循环【社区一图流 + 机制推导】

原文思路「铜须-发现鱼-海藻护卫不断打出鱼人，手牌中的裁脍鱼人获得成长」的执行链路：

1. 场上留 **布莱恩·铜须**（战吼触发两次）。
2. **海藻护卫** 发动(1) → 触发一个友方随从的战吼；指定 **蛮鱼斥候（发现鱼）** → 因为它带铜须，战吼**发现两张鱼人牌**。
3. 把发现的鱼人打出去 → 手牌中的 **裁脍鱼人** 每用一张鱼人牌就 +6/+6（在你手牌中时即成长）。
4. **暮光猎潮者**（对本随从施放法术 → 手牌最左边 +8/+8）与 **萨满招潮者**（对鱼人施放法术 → 手牌+场上鱼人 +3/+3）负责用酒馆法术把「手牌左侧」堆成怪物。
5. 战斗开始：**合唱鱼人** 获得你手牌中所有随从牌的属性值 → 一次性把整手牌的身材变成场上身材。
6. **手牌顺序是硬性操作点**：暮光猎潮者/浊盐远行者/未来鱼人/鱼人语实用手册全部只buff「**手牌最左边**」的随从，所以要刻意把最大收益的胚子放在手牌最左。

### 连招 3：关键词/下毒路线

- **下水道逃生鱼人**（5 星 7/7）发动(1) 给另一个鱼人 +7/+7 **和一个随机额外关键词**；**气泡枪手**（1 星战吼）与 **鳛芙的学徒**（4 星回合结束）提供随机额外关键词；**进化始祖**抉择给圣盾或烈毒。
- **海鲜乱炖**（3 星法术）：使一个随从 +1/+1，「你的战队中每有一个不同的额外关键词就重复一次」——关键词越多，一次法术的收益越高，所以**先铺满关键词，再打出海鲜乱炖**。
- **浅鳍秘法师 / 邪火咒龙**永久提高酒馆法术的加成；**多彩幼龙**（用户名单中的法强/法术来源）在数据库中实为 3 星龙族的 **红色多彩幼龙**（`BG34_638t`，战吼：本局对战中你的酒馆法术使随从额外获得 +1 攻击力）与 **黑色多彩幼龙**（`BG34_635t`，+1 生命值）、**蓝色多彩幼龙**（`BG34_634t`，随机获取一张消耗 2 枚铸币的酒馆法术牌）、**绿色/青铜多彩幼龙**（`BG34_636t` / `BG34_637t`，给其他龙加身材）——社区一图流所说的「多彩幼龙养法强」指的是红/黑两条，金色版为 +2 攻击力 / +2 生命值。
- 【官方预览】36.6.3 加快了海鲜乱炖与活化艾泽里特的动画结算速度，等于降低这条线的操作时间成本。

- **注意**：`裁脍鱼人`、`下水道逃生鱼人`、`天诞逃生飞龙`、`小瞎眼`、`茉艾拉·铜须` **均未出现在该签名列表中**——但这**不能推出它们无用**：签名统计的是对局结束时的场面构成，而裁脍鱼人/逃生飞龙等经常停留在**手牌**、或在结束前被替换掉。
- 【官方预览】官方在 36.6.3 前直接点名「下毒鱼恐怕更会大削」，最终落点是砍飞行专家（只能拉鱼人）＋加强下水道逃生鱼人（4 星 4/5 → 5 星 7/7）。
- 【二手攻略】S11 攻略的克制关系仍具参考性：鱼人内战大概率互毒，身材优势被抹平，胜负取决于战斗频率与毒的量；同时成型的复生/圣盾烈毒体系对「单点大身材」阵容（如元素雷暴流）有天然克制——1/10 的怒胆贴一层毒就能换掉一个千血大哥。
- 【机制推导】手牌鱼的天然弱点：**收益全部延迟到战斗开始**（合唱鱼人），招募阶段战力极弱，容易被中期高节奏阵容压血；且极度依赖**手牌左侧 buff 的指向性**，一旦铜须/合唱鱼人缺席，整手牌身材无法兑现。
