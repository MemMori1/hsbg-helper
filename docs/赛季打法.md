## 1. 数据来源与核验方法

### 1.1 本季实测牌池（A 级）

`tools/dump_pool.py` 从 5 份真机 `Power.log` 里抓取**真的出现在商店 `TB_BaconShop_DragBuy` 槽位（`tag=2442`）**的随从：

- 命中 **207** 张随从（另有 37 张只在场上出现过，从未进店）
- 按种族（一张牌可能有多个种族，故合计大于 207）：
  亡灵 22 / 海盗 22 / 野兽 22 / 恶魔 21 / 元素 21 / 龙 20 / 鱼人 17 / 野猪人 16 /
  机械 13 / **畸变怪 12** / 全类型 4 / **纳迦 2**（仅 `厄运先知`、`火鳞囤积者`）/ 无种族 24
- 产物：`data/pool_current.json`

⚠️ **牌池是下限不是全集**：6–7 星牌出场率低，5 局很难抓全（例如 6 星龙 `BG36_241` 赤红守备巨龙就没抓到）。
**1–5 星基本完整，6–7 星只能当参考。**

### 1.2 卡表（A 级）

`data/cards_zhCN.json` —— HearthstoneJSON 镜像构建，5,787 张战棋卡（含随从 / 法术 / 饰品）。

### 1.3 俗称到 CardID 的绑定（C 级，但可执行核验）

攻略文章用的是社区简称（「摩托猪」「仙女龙」「宰大哥」），和游戏内卡名经常对不上。
`tools/comp_cards.py` 把每条俗称显式绑定到一个 CardID 并核对：

```bash
/usr/bin/python3 tools/comp_cards.py          # 打印完整卡表
/usr/bin/python3 tools/comp_cards.py --check  # 只列出查不到的绑定
```

本档第 5 节的卡表就是这个工具的产物，**不要手抄**。

## 4. 各打法详解

每个打法分两层：**核心牌表是 A 级**（卡文直接读自卡表，可复现），
**打法要点是 B 级**（外部攻略，标注出处）。凡我没能证实的，写「未找到」。

### 4.0 本季机制如何组合出这些打法（A 级推断）

看懂这些打法只需要三条本季机制：

1. **进击（`BACON_RALLY`）**：己方回合发起攻击后触发 → 产生了「野兽 / 龙 / 野猪人」这一整类**回合内多次触发**的打法。
2. **发动（`X` 金）**：花金币主动触发 → 是**把金币换成资源**的阀门，也是「电表倒转」类循环的接口。
3. **黑暗之赐 / 饰品**：四选一、三选一的外挂增益 → 决定同一套牌的上限。

龙虾亡语触发（`瑞文` 双倍、`陆行鸟` 额外触发最左亡语）→ **龙虾效果自我提升**，越打越大。
